NOPerf · plugins for the Nuclear Option Linux dedicated server

What we learned about Nuclear Option’s server

We made a few small server jobs cheaper. We have not shown that the server as a whole runs faster, and we have not yet tested real players joining.

Reading the charts: smaller bars mean less work for the server. “ms” means milliseconds. We timed the work in each simulation cycle, excluding waiting for the frame-rate limit. These numbers are not FPS.

What changed

Three optional plugins do small, often-repeated jobs with less effort. A fourth only measures. The aim is to keep the game’s choices unchanged.

  • Find nearby units with less bookkeepingOn by default
  • Reuse temporary wreck listsOff · experimental
  • Check road points fasterOff · experimental
  • Optional measurementOff

Did it make the server faster?

Not that we could show.

We made this small task cheaper. The rest of the server still has work to do.

Lower means less work, but the two battles played out differently, so this cannot show whether the plugins helped or hurt.

What we saw when it slowed down

Late in the mission, the game did more physics updates in each frame. Each update also took more time. We have not yet found the cause.
