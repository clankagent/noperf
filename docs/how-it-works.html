How finding nearby units works

The server often needs a list of nearby units. Spatial builds the same list with less bookkeeping.

The map is split into areas. To find nearby units, the server checks the areas around a spot and lists the units inside them.

Technical details

In the real game, areas are grid cells, visited column by column, and each cell’s units are read from last to first. Duplicates and empty (null) entries are kept. The query details page walks through a fuller example with those cases. The other plugins are described in the developer guide.
